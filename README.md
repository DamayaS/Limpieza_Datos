# Limpieza_Datos
Proceso de limpieza, normalización y transformación a JSON de tres datasets públicos (Junta de Andalucía e Incidencias de San Francisco) con Python y Pandas. El proyecto diagnostica problemas de calidad bajo el marco de Jarke et al., estandariza tipos, fechas (ISO 8601) y variables, y modela esquemas JSON sin redundancias.
